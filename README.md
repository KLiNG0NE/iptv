## IPTV ##

Dies ist eine M3U-Liste mit kostenlos und legal verfügbaren TV-Sendern für deutschsprachige Zuschauer.

Die Liste kann über den folgenden Link in Plex, Kodi oder dem VLC Media Player aufgerufen werden:

```
https://raw.githubusercontent.com/KLiNG0NE/iptv/main/iptv.m3u8
```

Kurz-URL:

```
https://tinyurl.com/klingtv
```
